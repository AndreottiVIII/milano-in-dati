# Milano in dati

Milano raccontata con i dati aperti, in quattro filoni:

1. **Temperature**: Milano Brera dal 1763 a oggi.
2. **Donne nelle vie**: quante strade di Milano portano il nome di una donna.
3. **Beni culturali**: il catalogo nazionale ICCD, filtrato su Milano.
4. **Elezioni**: i risultati per sezione dal 1979 a oggi.

Sito: https://andreottiviii.github.io/milano-in-dati/

Nel repository ci sono i programmi, le note sulle fonti (`JOURNAL.md` e `NOTE.md` di ogni filone) e il sito (`docs/`).
I dati grezzi non ci sono: si riscaricano con i programmi in `*/scripts/`. Alcune fonti non permettono di ripubblicarli.
